1. Executive Summary

Speakora is a mobile-first English learning product focused on structured CEFR lessons, interactive exercises, timed AI speaking practice, and scenario-based role-play voice chats. The platform has three surfaces:

  • Mobile app (Expo / React Native) — learner experience
  • Backend API (FastAPI / PostgreSQL) — auth, curriculum, progress, AI voice
  • Admin panel (Next.js) — curriculum content studio
Current release focus: A1 Unit 1 “Introducing Yourself” with 10 lessons, sequential unlock (exercises + speaking), 10 role-play scenarios (4 minutes each), branded splash, exercise feedback tones, and profile progress overview.

8. Learning Path & Lesson Unlock Rules

Unlock rule (important): A lesson unlocks the next lesson only after all exercises are answered correctly and the learner finishes that lesson’s speaking session.

8.1 Path UI states

StateMeaningUI
completedUserProgress.is_completed = trueGreen node with check
currentFirst incomplete lessonBlue pulsing node (tappable)
lockedLater incomplete lessonsPink/locked node (disabled)

8.2 Completion pipeline

  1. Each correct unique exercise updates LessonProgress (exercise score).
  2. When every exercise in the lesson is correct → LessonProgress.is_completed = true.
  3. Speaking session POST /api/v1/speaking/sessions/{id}/end calls mark_lesson_complete_after_speaking.
  4. If exercises are done, sets UserProgress.is_completed = true (path unlock).
  5. Mobile speaking screen shows Back to unit and the Learning Path reloads on focus.
Greetings (exercises → speak) → unlock Introducing yourself Introducing yourself (exercises → speak) → unlock Personal information Personal information → … → Unit examination

9. Exercises System

9.1 Supported types

TypeLearner UI
multiple_choice / mcqTap option list
fill_blankText input
sentence_orderingTap tokens into order

9.2 Attempt rules

  • Maximum 3 tries per exercise
  • Wrong answers play negative tone + show remaining tries
  • Correct answers play positive tone + show explanation
  • After 3 fails, correct answer is revealed and learner can continue
  • Attempts posted to POST /api/v1/exercises/{id}/attempts

9.3 Feedback tones

  • Assets: assets/audio/correct.*, assets/audio/incorrect.*
  • Helper: mobile-app/src/lib/feedbackTones.ts (preload + play + light vibration)

10. Speaking Practice (Voice Chat)

  • Route: /lesson/[id]/speak
  • Duration: 3 minutes countdown timer
  • Hold-to-talk microphone; audio uploaded as AAC/M4A
  • Backend: create speaking session → message turns (STT → tutor reply → optional TTS) → end session
  • On finish: return to Learning Path; unlock next lesson if exercises were completed

10.1 Speaking API

POST/api/v1/speaking/sessions/{id}/endClose session; may set lesson_completed

15. Database & Progress Model

15.1 Core tables (conceptual)

  • users — accounts
  • courses → units → lessons → exercises
  • exercise_attempts — each submit
  • lesson_progress — exercise score / exercises_completed flags
  • user_progress — path completion + AI talk time (unlock source of truth)
  • speaking_sessions / speaking_messages — voice turns
  • learning_sessions — timed practice blocks for streaks/stats

15.2 Unlock source of truth

Learning Path reads UserProgress.is_completed via GET /api/v1/courses. Exercise-only completion updates LessonProgress but does not unlock the next node until speaking ends successfully with exercises done.

16. AI Pipeline (Groq)

  1. STT: Whisper large-v3 transcription of uploaded audio
  2. Chat: JSON reply with reply + grammar_correction
  3. Modes: tutor correction prompt (lessons) vs role-play character prompt
  4. TTS: Orpheus (optional; fails soft if unavailable)
  5. Audio format: client records AAC/M4A; backend sniffs magic bytes before Whisper
Ops note: Keep GROQ_API_KEY in backend/.env only. Never commit secrets. Accept TTS model terms in Groq console if voice playback is required.

19. Known Flows & Acceptance Criteria

19.1 Lesson unlock acceptance

  1. Open Learning Path → only first incomplete lesson is tappable
  2. Complete all Greetings exercises (tones play) → Speaking opens
  3. Finish speaking → Back to unit
  4. Greetings shows completed (green); Introducing yourself becomes current (blue)
  5. Repeat for Introducing yourself → unlocks Personal information

19.2 Role play acceptance

  1. Open Role Plays → see 10 image cards
  2. Start a scenario → timer centered above orb
  3. Hold mic → partner replies in character
  4. Exit available during chat and after finish

19.3 Branding acceptance

  1. Native/loading splash is indigo with robot (not plain white name-only)
  2. In-app splash shows Speakora robot + animated presence
  3. Admin titles show SPEAKORA / Speakora Content Studio
